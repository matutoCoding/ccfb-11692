# 徒步地形制图与晕渲系统

浏览器内运行的地形制图工具：TypeScript + WebGL2，无需服务器，所有数据保存在浏览器 localStorage。

## 启动

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 生产构建（含类型检查）
npm test         # 精度核对测试（vitest）
```

## 功能页面

| 页面 | 功能 |
|------|------|
| 地图 | 项目增删改复制，存 localStorage，导出/导入 JSON |
| 高程导入 | Esri ASCII Grid (.asc) 导入，NODATA 缺失值识别与邻域均值填充；解析式测试地形生成（峰顶高程精确已知） |
| 晕渲样式 | 光源方位角/高度角调节，最多 3 方向加权混合；分层设色色带编辑（增删色标、预设） |
| 等高线 | 间距、计曲线间隔、首曲线/计曲线颜色线宽、计曲线高程注记 |
| 路线标注 | 单击画线，自动计算距离/累计爬升/累计下降，剖面图 |
| 出图 | 纸张（A3/A4/A5）、方向、DPI、比例尺，导出 PNG（含比例尺条、指北针、图名） |
| 设置 | 默认值、存储管理、**精度自检** |

## 精度保证（自动化测试 + 浏览器自检同一套逻辑）

- **等高线位置**：marching squares 主实现（连通多段线追踪，`src/core/marchingSquares.ts`）与独立参考实现（逐单元线段法，`src/core/marchingSquaresRef.ts`）逐段核对，演示地形 + 含噪声地形 + 含缺失值地形全部等值面**偏差 0.00 格**（限差 0.01 格）；平面场等值线位置对解析真值误差 < 1e-5 格（Float32 存储精度极限）。
- **累计爬升**：平面场与解析解误差 0.0000%；已知峰高（1200m）高斯峰山脚→峰顶与解析高差误差 0.000%（限差 1%）；另有 10 万步超精细采样参考对比。
- 两实现必须遵守同一数学约定（见 `marchingSquaresRef.ts` 开头注释）：角点 >= 等值记高、边交点线性插值、鞍部用四角均值裁决、NaN 单元跳过。

## 主要实现说明

- **渲染**：WebGL2 着色器实时合成山体晕渲（中央差分梯度、多光源加权）与分层设色（256 级 LUT 纹理）；等高线/路线/注记用 2D canvas 叠加层。
- **出图**：离屏 WebGL 画布按纸张 mm × DPI 渲染地形层，再合成矢量要素，比例尺放不下整幅图时自动调整比例尺适配。
- **高程栅格**：内部第 0 行 = 最南行（.asc 导入时翻转），缺失值统一为 NaN。
